# 🧩 Interactive K-Means + PCA Explorer

An interactive unsupervised Machine Learning project demonstrating clustering and dimensionality reduction.

## 🚀 Live Demo

👉 https://masmi-kmeans-pca.streamlit.app/

## What It Does

- Uses the scikit-learn Wine dataset
- Analyzes 178 samples and 13 numeric features
- Tests K-Means from K=2 to K=10
- Selects the best clustering result
- Uses PCA for dimensionality reduction
- Provides interactive 2D and 3D cluster visualization

## Results

- Best K: **3**
- Silhouette Score: **0.2849**
- PCA used for interactive cluster exploration

## Technologies

Python • pandas • NumPy • scikit-learn • K-Means • PCA • Plotly • Streamlit
